# psd-paint

선화 PSD에 밑색 레이어를 자동으로 깔아 준다. 작가가 PSD 안에 `참고` 폴더를 만들고 영역마다 점이나 낙서로 힌트를 칠하면, 선화로 닫힌 영역을 힌트 색으로 채워 부위별 레이어(`머리`, `피부`, `재킷` …)로 나눠 저장한다.

## 참고 레이어 규칙

```
참고 (폴더)
 ├ 머리    ← 머리 영역마다 점 하나 또는 낙서
 ├ 피부
 ├ 재킷
 └ …
```

- 하위 레이어 이름이 결과의 밑색 레이어 이름이 된다.
- 칠한 색이 그 영역의 밑색이 된다. 같은 레이어 안에서 인물마다 다른 색을 써도 된다.
- 영역 안에 점 하나만 찍어도 영역 전체가 칠해진다. 한 영역에 힌트가 여럿이면 가장 많이 칠한 색을 쓴다.
- 힌트가 없는 큰 영역은 칠하지 않는다. 힌트가 없는 작은 영역(400px 미만)은 가장 많이 맞닿은 이웃 영역을 따른다.
- `참고`를 폴더가 아닌 레이어 하나로 두면 색마다 `색_RRGGBB` 레이어로 나뉜다.
- 결과 PSD에서는 `참고` 폴더를 숨긴다.

## 결과

- `선화` 폴더 바로 아래에 `밑색` 폴더를 만들고, `참고` 폴더와 같은 순서로 레이어를 넣는다.
- 레이어는 마스크 없는 일반 픽셀 레이어다.
- 원본은 건드리지 않고 `원본이름_밑색.psd`로 저장한다.

## 사용법

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 앱 (GUI)

```bash
.venv/bin/python -m psdpaint.gui
```

- PSD 파일이나 폴더를 창에 끌어 놓거나 [파일 추가…]로 고른다. 같은 파일은 한 번만 들어간다.
- [▶ 밑색 칠하기]를 누르면 순서대로 처리한다. 파일마다 진행률과 결과를 보여 주고, 실패한 파일은 건너뛴다.
- [중지]는 지금 처리 중인 파일을 마친 뒤 멈춘다.
- 완료한 파일을 고르면 오른쪽에 미리보기가 나온다. [파일 열기]는 연결된 앱(예: 클립스튜디오)으로 열고, [폴더에서 보기]는 Finder·탐색기에서 위치를 보여 준다.
- 설정은 다음 실행 때도 유지된다.

### 명령줄 (CLI)

```bash
# 여러 파일을 순서대로 처리한다. 실패한 파일은 건너뛰고 계속한다.
.venv/bin/python -m psdpaint 1화.psd 2화.psd 3화.psd -o 결과폴더
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-o`, `--out` | 원본과 같은 폴더 | 결과 폴더 |
| `--suffix` | `_밑색` | 결과 파일 이름 뒤에 붙일 말 |
| `--line` | `선화` | 선화 레이어가 든 폴더 이름 |
| `--hint` | `참고` | 힌트 폴더 이름 |
| `--offset` | `2` | 밑색 바깥 윤곽을 안쪽으로 줄이는 px |
| `--gap` | `2` | 끊긴 선의 틈을 막는 정도(px) |
| `--boundary` | `컷*`, `*테두리*` | 선화 외에 경계로 쓸 레이어 이름 패턴. 여러 번 지정할 수 있다 |

컷 테두리는 `--boundary` 패턴에 맞는 보이는 픽셀 레이어로 찾는다. 숨긴 레이어와 캔버스 절반 이상을 덮는 레이어(컷 배경 등)는 경계에서 뺀다.

## 처리 순서

1. 선화와 컷 테두리를 합쳐 경계를 만들고, 끊긴 선을 `--gap`만큼 두껍게 해 닫힌 영역으로 나눈다.
2. 영역마다 `참고` 힌트를 대응한다.
3. 선 아래까지 밑색을 넓힌다.
4. `머리` 레이어는 잔머리 가닥 사이 작은 틈을 채운다.
5. 밑색 바깥 윤곽을 `--offset`만큼 안쪽으로 줄인다.
